# دليل وكيل Wi‑Fi لنظام Android

تطبيق Android صغير يشرح كيفية فتح إعدادات Wi‑Fi وإدخال إعداد وكيل يدوي لشبكة مصرح لك باستخدامها.

## ما يفعله التطبيق

- يفتح صفحة إعدادات Wi‑Fi في Android.
- يشرح خطوات ضبط وكيل يدوي باستخدام عنوان الخادم والمنفذ اللذين يقدمهما مسؤول الشبكة.
- لا يطلب أذونات شبكة، ولا يشغّل خادم وكيل، ولا يمرّر أو يسجل أو يفك تشفير حركة المرور.

## حدود النظام

تطبيقات Android العادية لا تملك عادةً صلاحية تغيير وكيل Wi‑Fi للنظام من دون تدخل المستخدم أو صلاحيات نظام/إدارة مناسبة. كما أن جعل الهاتف جسرًا شفافًا أو تشغيل Wi‑Fi كعميل ونقطة وصول في الوقت نفسه يعتمد على الجهاز وإصدار Android، ولا يتيحه هذا التطبيق. لمشاركة الاتصال استخدم ميزة نقطة الاتصال المدمجة أو جهاز راوتر/مكرّر مناسب.

## البناء

يتطلب Android Studio وJDK 17 وAndroid SDK 35. افتح هذا المستودع في Android Studio ثم شغّل مهمة `assembleDebug`، أو استخدم:

```bash
gradle assembleDebug
```

ملف APK التجريبي الناتج يكون عادةً في `app/build/outputs/apk/debug/app-debug.apk`.
